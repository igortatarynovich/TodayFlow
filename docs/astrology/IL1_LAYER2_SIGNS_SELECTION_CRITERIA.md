## 0. Two scores, never mixed

Parent step 8 is quality × independence × relevance × legal accessibility. For Layer 2 those axes split:

| Score | What it is | What it is not |
|-------|------------|----------------|
| **Epistemic** | Does this locus cover the cell, independently, as principle, without lemma collapse or ontology creep | Popularity, history, jacket, TOC, “we already cataloged it” |
| **Access** | Can we legally read the named pages now | Quality. Readable ≠ better grammar |

Access may change **ingest order** on the shortlist. It must not decide **who belongs on the shortlist** for cell C (psychological structure textbook). That cell sets the grammar of `motivation` / `strengths` / `excess` / `deficiency`. Picking it by readability repeats the planet error.

## 1. Locked criteria

Apply per **cell** (school × constituent band), not per “book about signs.”

### Hard gates (fail = out of that cell)

| ID | Criterion | Fail looks like |
|----|-----------|-----------------|
| **L2-C1** | Covers the **named constituent** of that cell | “A book about signs”; planet-in-sign; sun-sign column |
| **L2-C5** | One work is not independent confirmation of itself via another title, edition, extract, or student restatement | Arroyo handbook confirming Arroyo Four Elements; Khaldea article confirming Pulse as a second school; Martin confirming Greene |
| **L2-C6** | Shared vocabulary ≠ shared lemma | `fire` / `cardinal` / `positive` treated as CORE or even as `supported` across schools |
| **L2-C15** | Extra categories do not expand Layer 2 ontology | New enum, new required slot, or “while we’re here” sidereal / Huber-API / evolutionary / dignity folded into the sign object |

Jacket, TOC, reviews, SEO, pirate dumps, and model memory **never** pass a hard gate. They are not evidence that a constituent is covered.

### Rank modifiers (epistemic)

| ID | Criterion | Direction |
|----|-----------|-----------|
| **L2-C2** | Principle-level explanation of how sign meaning is built | **Above** twelve finished portraits |
| **L2-C3** | Independent school line | **Above** a second author in an already-filled class |
| **L2-C7** | Explains **how** the value arises | **Above** enumerating the result (Aries = …) |
| **L2-C8** | Psychological candidate | Prefer if it **derives** motivation / excess / deficiency from structure (element × modality or another named generator). Penalty if it only describes twelve types |
| **L2-C9** | Humanistic candidate | Must stay cyclic / process / phase-task. Penalty if it becomes personality psychology (false CORE with C) |
| **L2-C10** | Professional candidate | **Not needed to start** if it only repeats the modern four-element + cardinal grid already used as *other lemma* by psych/humanistic consulting books |
| **L2-C12** | Cookbook-risk | **Explicit penalty.** 12 portraits, keyword tables, sun-sign tone. May still be a later densify locus, not a first fill |
| **L2-C13** | Coverage redundancy | **Penalty.** A second source in the same school is justified only if the first does not close the constituent **or** an independence check is required. Classical classification is already saturated — more classical is default-reject |
| **L2-C14** | Historical importance | **No boost** unless the locus covers the current cell. Firmicus/Dorotheus/Brennan do not outrank Houlding ontology on that ground |

### Sequencing only (not epistemic)

| ID | Criterion | Use |
|----|-----------|-----|
| **L2-C4** | Direct-readable author text | Prefer for **first extract** among already-shortlisted loci |
| **L2-C11** | Access (readable / partial / NEED_OWNER) | May reorder ingest. Must **not** promote a weaker grammar into cell C |

**L2-C4 and L2-C11 do not make Rudhyar the psychological structure textbook.** Pulse of Life is a humanistic candidate. Its readability is a sequencing fact for the humanistic cell, not a reason to open later-interpretive object slots in this pass.
