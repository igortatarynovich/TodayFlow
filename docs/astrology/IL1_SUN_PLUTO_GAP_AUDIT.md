CORE is still correctly **unscored**. A first CORE pass is not “pick the nicest modern sentence.”

Minimum, per lemma:

1. The **same normalized claim** (not merely the same planet) appears in **more than one school class**.
2. Conflicts listed in §3 are not silently collapsed.
3. Ledger-only rows (medical, iron, healing, collective disruption, orbit-fact, excluded psychotic-crisis example) stay out of `object.function` / `object.domains`.
4. Human review (`review_status` past `extracted` / `compared`).

Practical implication:

- **No outer-planet CORE** until the **same lemma** appears in more than one school class. Uranus: disruption ≠ transform/through. Neptune: dissolution ≠ ecstasy/prenatal. Pluto: reconstruction ≠ celestial-seed. Greene Outer Planets remains NEED_OWNER; another independent psychological source may fill the psych gap.

- **No Venus CORE** from moisture + bonding + inward-way: four different categories, currently one class each except classical moisture.
- **No “Saturn = structure” CORE** from the current mix. Cold/dry/malefic may later become CORE *if* another class states those lemmas; Hand/Greene currently do not.
- **Do not** treat Watters + Hand as two school classes. Both are `professional`.
- **Do not** treat Ptolemy + Lilly as CORE. Both are `classical`.

Until those gaps close, engine primary themes cannot be sourced from this catalog (`core` ∪ `supported` only; `supported` today is classical-internal, plus Saturn classical+traditional on a few lemmas). Draft objects remain lookup material, not product voice.
