## Job of Act 3 (one sentence)

После «кто» и «почему» человек должен увидеть **один новый узел** — не пересказ recognition_line и не список сил.

Чувство: «Вот этого я ещё не замечал.»

---

## Locked cascade (text form)

```text
[Заголовок узла — ловушка / сила / повтор]
  одна фраза сути (не совет «сегодня»)
        ↓
На чём стоит вывод
  2–4 calc anchors (факты) — без ложной причинности имени
        ↓
Что помогает
  один практический ход (не аффирмация)
        ↓
Как уже проявлялось   ← только с living evidence; иначе omit
  короткая цитата/поведение
```

**Запрет:** три колонки Strengths / Limits / Patterns как равные карточки.  
**Запрет:** перефраз Act 1 line другими словами.

## Sample A — birth-only / Explorer · life_path 7 (no living)

Фикстурный дух: глубина + дистанция; имя из пути 7.

```text
Самая большая ловушка
  Ты долго собираешь ясность внутри — и откладываешь первый внешний шаг.

На чём стоит вывод
  · Число пути 7 (сценарий глубины)
  · Солнце / стихия — как проявляется «сначала понять»
  · (без ASC, если нет времени)

Что помогает
  Назвать вслух один маленький шаг до того, как «всё сложится».

Как уже проявлялось
  — omit (нет living)
```

**Проверка отличия от Act 1–2:**  
Act 1 сказал бы «ты видишь структуру». Act 2 — «имя из пути 7 / солнце расширяет».  
Act 3 говорит **промедление перед внешним шагом** — это новый угол.

## Sample B — с living (когда есть)

```text
Повтор, который дорого стоит
  Ясность ломается, когда решение принимают на скорости.

На чём стоит вывод
  · Рост / growth_zones из контракта
  · Опоры why (коротко, не dump)

Что помогает
  Один тихий проход перед решением.

Как уже проявлялось
  «опять поторопился» (living evidence as context, not proof)
```

## Acceptance for scenarist (before #4 visual)

| Check | Pass if |
|-------|---------|
| Novelty | Узел не равен recognition_line и не равен Why title |
| One node | Один каскад, не три секции |
| Anchors | Только факты, которые есть в why/contract — без выдумки |
| Help | Один ход; не дублирует Effort vector дословно, если Effort уже на экране |
| Living | Omit, если пусто — не placeholder |
