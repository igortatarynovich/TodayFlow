A hand-built, currentColor line-icon set (1.5px stroke) — used for nav items, Today domain chips, and small in-card glyphs. Not a full library; add new glyphs in the same stroke weight when a screen needs one.

```jsx
<IconSun className="nav-icon" />
```

For zodiac signs, planets, elements and archetype symbols use the real SVG sets in `assets/icons/` instead — those are the product's actual purchased icon files, not hand-drawn glyphs.
