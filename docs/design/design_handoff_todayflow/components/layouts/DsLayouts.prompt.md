Page-level shells: `DsMarketingPage`/`DsMarketingSection` compose the full-bleed alternating-tone sections of the marketing site; `DsAppShell` pairs a sidebar with a padded content area for the product app.

```jsx
<DsMarketingPage nav={<DsMarketingNav .../>}><DsMarketingSection tone="muted">...</DsMarketingSection></DsMarketingPage>
```
