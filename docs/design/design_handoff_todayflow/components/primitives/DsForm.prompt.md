Form field set — warm cream inputs, pill-shaped chips and classifiers, gold checkbox.

```jsx
<DsTextField label="Email" placeholder="you@example.com" />
<DsChipField selected>Morning person</DsChipField>
```

`DsSearchField` bundles a search icon; `DsChipField` is a toggle chip (selected state fills with gold wash); `DsClassifier` is a static pill label (e.g. "Full report"); `DsCheckbox` is a custom gold-filled checkbox replacing the native control.
