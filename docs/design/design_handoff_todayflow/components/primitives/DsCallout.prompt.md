DsCallout is a thin left-rail callout for interpretive copy — the tone sets both the rail color and an uppercase label, never a full-bleed colored block.

```jsx
<DsCallout tone="avoid">Overcommitting before noon — one thread beats five urgent ones.</DsCallout>
```

Tones: `insight` (gold), `practice` (numerology purple), `help` (soft green "gift"), `avoid` (soft rust "watch for"). `DsQuote` is a serif italic pull-quote with a gold rule; `DsEmph` highlights a key phrase inline; `DsCapsule` is a small pill-shaped inline chip.
