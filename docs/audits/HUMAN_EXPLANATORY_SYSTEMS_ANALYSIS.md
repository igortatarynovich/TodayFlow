## 0. Зачем этот документ

Вопрос исследования:

> Какие элементы и механики повторяются в успешных объяснительных системах человека — независимо от культуры, эпохи и отношения к истине — и какую задачу мозга они закрывают?

Не вопрос:

> Что должен делать TodayFlow?

TodayFlow появляется **только после** research-цепочки ниже. До этого — запрет на продуктовые выводы в этом файле (§13).

**Порядок проходов (зафиксирован):**

```text
Intersection v0                         ✅
  → Failure matrix                      ✅
    → механизмы восстановления R*       ✅ deepen v0.2
      → возобновление неопределённости U* ✅ deepen v0.2
        → пересмотр E01–E22             ← next
          → минимальный набор механизмов
            → только затем TodayFlow
```

Intersection отвечает: «что часто существует».  
Failure отвечает: «без чего / при каком поломке система перестаёт удовлетворять потребность в объяснении».  
Только failure даёт **причинность** (механизм vs совпадение частоты).

## 1. Метод (как инженер разбирает двигатель)

| Шаг | Действие | Запрещено |
|-----|----------|-----------|
| 1 | Зафиксировать когнитивную задачу системы *вообще* | «Наш продукт должен…» |
| 2 | Составить инвентарь кандидатных элементов модели | Объявить элемент обязательным без матрицы |
| 3 | Разобрать N систем по одному шаблону | Сравнивать «глубину философии» |
| 4 | Построить intersection (что часто) | Принять частоту за механизм |
| 5 | **Failure matrix** — одинаковые точки разрушения | Расширять список систем; «ужесточать E07/E19 примерами» до failure-pass |
| 6 | Механизмы восстановления (как модель живёт после конфликта) | Свести E19 к одной фразе «умеет объяснять ошибки» |
| 7 | Механизмы возобновления неопределённости | Путать acquisition wow с life-retention |
| 8 | Пересмотр E* только как вывод из 5–7 | Угадывать декомпозицию E07/E19 заранее |
| 9 | Убедительность ≠ истинность (литература) | Свести всё к Barnum |

**Единица анализа:** система как машина рационализации неопределённости.  
**Не единица:** вероучение, бренд, UI приложения, «правильная» астрология.

## 2. Когнитивная задача объяснительной системы (слой 1)

**Рабочая формулировка (H-cog):**

> Объяснительная система уменьшает неопределённость, давая человеку способ **встраивать события и состояния в устойчивую модель** («как устроено происходящее / как устроен я»), достаточную для ориентации и следующих ожиданий — без требования истинности модели.

Антропологическая петля (нейтрально к системе):

```text
событие / состояние
  → непонятность / несоответствие модели
    → напряжение
      → поиск объяснения
        → принятие «достаточно хорошего»
          → встройка в картину мира
            → ожидания / решения / повторное обращение к системе
```

**Не путать с:** снятием неопределённости (невозможно обещать), контролем исхода, научной верификацией.

**Открытый уточняющий вопрос (не закрыт):** насколько задача ближе к (a) assimilation в уже имеющуюся модель vs (b) периодической accommodation (перестройка). Скорее оба режима; вес — в профиле и в кризисе модели.

## 4. Карточки систем (механика, не содержание)

Шаблон на каждую:

1. Что объясняет  
2. Что принципиально не объясняет (или объясняет слабо)

## 6. Убедительность объяснения (не истинность)

Искать, не изобретать. Ниже — кандидаты свойств + статус опоры.

| Свойство | Суть | Опора / статус |
|----------|------|----------------|
| Узнаваемость | «Это про меня» | Forer/Barnum effect; subjective validation — **частично** объясняет принятие *общих* формулировок; **не** объясняет многолетнее углубление в сложные системы |
| Позитивный уклон | Легче принять мягко-лестные описания | Pollyanna / positivity bias (связан с Forer) |
| Авторитет источника | Вес от метода/традиции/эксперта | Empirically усиливает acceptance feedback |
| Согласованность с prior model | Assimilation first | Predictive processing / Piaget assimilation — **рабочая рамка**, не «доказано для астрологии» |
| Внутренняя непротиворечивость | Сегодня не отрицает вчера без моста | Логика удержания модели (аналитическая) |
| Связь прошлого с настоящим | Биография встраивается | Narrative coherence (психология нарратива) — кандидат |
| Порождаемость ожиданий | Можно ждать «если модель верна…» | Predictive processing |
| Объяснение промахов | E19 | Наблюдаемо во всех зрелых системах |
| Конкретность «достаточная» | Не обязательно научная; достаточно для действия/ориентации | Открыто: порог конкретности различен у профилей |
| Улучшаемость | Модель становится богаче | E20; иначе novelty выгорает |

**Явный вывод-ограничение:** свести успех систем только к Barnum = ошибка анализа. Barnum объясняет *входную убедительность портрета*, не *временной двигатель* и не *skill-depth retention* (астрология, HD, Enneagram, Jung).

### 9.1 Шкала в матрице

## 12. Возобновление неопределённости (U*) — deepen

Успешное объяснение **уничтожает причину обращения**. Life-retention требует U*: откуда берётся **новая** неопределённость, когда старая закрыта.

| ID | Механизм | Откуда новая неопределённость | Ядро у |
|----|----------|-------------------------------|--------|
| **U1** | Время / эпоха | Завтра иная конфигурация при том же «я» | Astrology; Num слабее; HD transit |
| **U2** | Новая ситуация / вопрос | Разрыв модели из жизни | Tarot; Jung; все частично |
| **U3** | Предписанный эксперимент | Правило жизни снова на проверке | HD |
| **U4** | Лестница глубины | Неизвестный слой той же модели | Ennea; Astro technique; HD gates; Jung |
| **U5** | Другой человек | Новый объект для той же оптики | Synastry / HD / MBTI / Ennea |
| **U6** | Соц-контент | Внешняя лента вопросов о типе | MBTI часто *вместо* U1 |
| **U7** | Кризис модели | Старое объяснение больше не держит | Jung; hard transit; Ennea growth |

### 12.1 Горизонты: что система может сказать нового

| Система | День | Месяц | Год+ | Главный U* | Что будет, если U* отключить |
|---------|------|-------|------|------------|------------------------------|
| **Astrology** | Транзит/луна/день | Лунации, ретро, ингрессии | Солар, сатурн, прогрессии | **U1** (+U4,U5,U7) | Натал-музей → профиль F7 как у MBTI |
| **Numerology** | Личный день | Личный месяц | Личный год / пины | **U1** (бедный) | Остаётся ярлык числа → F7/F8 |
| **Tarot** | Новый вопрос | Повторные расклады по сюжету | Эволюция практики чтения | **U2** (+U4) | Без вопросов колода молчит; календарь не спасёт |
| **HD** | Жить strategy сегодня | Проверка experiment | «Годы» эксперимента; слои ворот | **U3** (+U4, U1 partial) | Без experiment = статичный bodygraph → F7 |
| **MBTI** | Почти ничего из ядра | Почти ничего | Смена самолейбла редко | **U6** (вне ядра), слабый U5 | Без ленты/сообщества → F7+F11 |
| **Enneagram** | Самонаблюдение паттерна | Работа уровня/крыла | Долгая growth-лестница | **U4** (+U2,U7) | Выученный номер → медленный F7; F2/F11 живы |
| **Jung** | Сон/синхрония | Фаза анализа | Индивидуация | **U2+U7** (+U4) | Без живого материала / проводника → стоп |
| **Big Five** | — | — | Редкие ретесты | почти нет | Сразу потолок как life-OS |

### 12.2 Сценарные цепочки (закрытие → новая дыра)

**Astrology (U1):**  
«Понял свой натал» (неопределённость портрета↓) → небо сдвинулось → «что этот транзит делает с *моим* наталом?» (новая неопределённость). Якорь тот же.

**Tarot (U2):**  
«Понял этот конфликт» → жизнь приносит другой конфликт / тот же через месяц → новый вопрос. Якорь не trait, а метод.

**HD (U3):**  
«Знаю, что Generator» → каждый день: «я следовал strategy?» → данные experiment. Неопределённость = соответствие жизни правилу.

**MBTI (слабый U в ядре):**  
«Я INFJ» → неопределённость↓ → следующий визит к системе не из модели, а из U6 («ещё статья») или U5 («тип партнёра»). Если U6 нет → F7+F10+F11.

**Enneagram (U4):**  
«Я восьмёрка» → «какой у меня уровень / wing / instinct?» → неопределённость смещается вглубь, не во время.

### 12.3 Связка failure ↔ U*

| Если нет сильного U* | Типичный путь смерти |
|----------------------|----------------------|
| Нет U1 и нет U2 | F11 + F7 (MBTI-core, Big5-as-life-OS) |
| Есть только U6 | Ушёл из ленты — система молчит |
| Есть U1 × стабильный якорь | Life-retention без смены «я» (astro-pattern) |
| Есть U2 | Retention = частота жизненных разрывов |
| Есть U3 | Retention = дисциплина эксперимента |
| Есть U4 без U1/U2 | Долго, риск F12 или потолок лестницы |
| U4 как единственный двигатель | Не закрывает F2 «что с *сегодняшней* ситуацией» |

### 12.4 Причинные выводы (не element-count)

1. **Life-retention требует U-двигатель**; наличие типов (E01) недостаточно (Big5, MBTI-ядро).  
2. **U1 и U2 взаимозаменяемы на уровне класса** (оба против F7×F11), но дают разный ритм: календарный vs событийный.  
3. **U4 ≠ U1**: глубина продлевает изучение; не обязана объяснять «сегодня».  
4. **U6 — костыль retention**, не свойство модели; сравнивать MBTI с astro по «популярности контента» = путать ядро и экосистему.  
5. **R* чинит модель; U* заново ломает покой** — разные подсистемы. Система с богатым R* и бедным U* долго не живёт после первого успеха.
