## 0. Баги (чинить отдельно от вкуса)

1. **Дублирование текста.** Блок «Избегать: …» на Чтении рендерится дважды подряд.
2. **Статичный подзаголовок-заглушка.** «Пять коротких глав — от изменения к вечеру.» повторяется под каждой секцией Чтения — дефолт вместо секция-специфичного текста (категория «Память о вчера»).
3. **Обезличенные ярлыки таймлайна.** «Сигнал дня» / «Короче шаг» без различимого смысла после jargon scrub.
4. **Экран 1 «Сюжет» дублирует Сводку.** Реальный нарратив (`opposing_forces`, `why_arose`) рендерится в Чтении, а не в Сюжете.

---

## 1. Принцип

Экран = одна задача. Свайп = продолжение. Один факт не дословно на двух экранах.

---

## Экран 0 — Сводка (Glance)

- Текстурная фраза (1–2 предложения из `conflict.why_arose`, не только `short_name`) — доминирует.
- Компактный индикатор 4 сфер (иконка/точка + цвет + короткий label, **без** `why_short`). Тап → deep-link на сцену Экрана 3.
- Ближайший сигнал — мелким текстом рядом (человеческий лейбл, не «Сигнал дня»).
- Тизеры 1–5 — без изменений.

## Экран 1 — Сюжет

`opposing_forces.a/b` + `why_arose` (+ `why_personal` только при `profile_depth=deep`, иначе omit) — связный рассказ «почему сегодня так». Фото — атмосфера; подпись = нарратив, не ярлык Сводки.

## Экран 2 — Символы

Карта дня открыта сразу. Число дня. Астрособытия дня (фаза Луны, ключевые транзиты) простым языком с фактом влияния.

## Экран 3 — Чтение

4 карточки сфер: что происходит → возможность → ловушка → действие. Без цвета/ритуала (→ Экран 4) и без астро (→ Экран 2). Без заглушек-подзаголовков и дублей.

## Экран 4 — Действие

Если/то, цель, практика — оставить. Добавить цвет/ритуал: плашка + одна строка «как использовать» + короткая «избегать».

## Экран 5 — Отклик

Tap/чек-ин — оставить. Убрать кросс-сейл («карта личности» / совместимость / Таро) с этого экрана.

---

## 2. Таймлайн

Визуальная шкала с валентностью (`favorable`/`caution`); каждая метка — различимый человеческий текст. Компакт на Сводке (nearest); полный вид — на Действии / Symbols rail.
