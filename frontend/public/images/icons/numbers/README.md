# Numerology digit icons

Metallic digits **1–9** for `NumberIcon` (life path, day number, profile orbits).

```text
{1-9}.webp   # 384×384, transparent
```

Source: `docs/design/assets/numbers.png`  
Masters: `docs/design/assets/number-glyphs/`  
Rebuild: `python3 scripts/crop_numbers_sheet.py`

No **0** on the sheet — `NumberIcon` falls back to text for unknown digits. Master numbers (11 / 22 / 33) compose two glyphs.
